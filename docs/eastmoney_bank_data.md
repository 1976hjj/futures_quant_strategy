# 免费银行财务数据源

数据管理页面独立选择「东方财富 · 免费公开数据」。无账号、无 Token，不调用 Tushare；原有数据源与原始仓库保留。

## 范围和操作

当前42家A股上市银行，名单见 config/eastmoney_banks.json。每次采集全部可获得历史报告与最新指标，保存14项银行财务字段；界面重点展示不良贷款率、拨备覆盖率、核心一级资本充足率、资本充足率、净息差五项覆盖。缺失值保留 NULL。此源不替代行情、复权、证券历史名册和其他行业财务来源。

选择截止日期 → 检查更新计划 → 开始增量更新。并发最多2路；每天按实际采集日期判断是否需要刷新，报告期不冒充采集日期。42家全部成功后发布银行专用仓库；任一家失败保留上次成功版本，失败原始证据仍归档。

## 启动

run.ps1 已加入独立数据管理服务，默认端口8774；现有回测服务仍为8773。启动脚本复用已运行的数据管理服务，避免打断其采集任务。

单独启动：`python scripts/serve_data_update_api.py --port 8774`。
前端可用 VITE_DATA_API_URL 配置数据管理API，默认 http://127.0.0.1:8774/api/v1。
命令行采集：`python scripts/sync_eastmoney_banks.py --end YYYY-MM-DD --workers 2`。

## 归档和研究约束

- 原始证据和每次标准化快照：data/eastmoney_bank_archive/runs/<run_id>/。
- 当前成功版本指针：data/eastmoney_bank_archive/checkpoint.json。
- 独立仓库：data/warehouse/eastmoney_bank.duckdb。
- 表 bank_financial_snapshots 追加保存采集版本；bank_financial_latest_versions 保留每个报告期最新采集版本；bank_financial_current 为本次42家最新报告。
- 每条数据保留来源、报告期、供应商公告日、实际采集时间和原始哈希。available_at 为实际采集时间；历史公告版本、资本口径未完成逐份原文核验，不能把今日下载的更正后历史数据直接认作过去已知数据。
- 早期缺公告日、异常比率等保留 quality_flags。最新报告异常时拒绝发布；历史异常单独标记待复核。
- 这是生产接入代码，不属于研究后需要删除的临时分析脚本。


## 2026-10-08 主源优先级

银行研究优先采用Tushare兼容Token数据，免费来源仅补充不存在或缺失且口径可比的字段。报价、PB与直接股息率沿用market模块；一般银行报表与BPS沿用financial模块；分红阶段与实施沿用corporate模块，不增加重复Token模块。银行专用比率在本轮标准Token接口中未返回，继续使用免费银行归档。

42家银行专项快照位于data/tushare_bank_archive/<run_id>，发布到data/warehouse/bank_token.duckdb；每次采集保留原始响应与SHA256。完整日行情仅使用daily_complete、adj_factor_complete、daily_basic_complete视图；当前日未过18点的数据只在原始快照中。bank_primary_research_panel按更新标记选择财务版本并保留每个来源，BPS缺失才采用免费值；贷款、存款账面口径不覆盖监管口径。bank_source_policy.json记录优先级。

数据管理现有3个模块显示bank_token_summary.json中的银行专项覆盖；这不是全市场更新，绝不修改全市场checkpoint日期。银行专项属于此次历史补取版本；后续常规7模块更新时，银行仍在全市场范围内采集。研究端选择版本须同时比较采集时间、公告日和字段口径，不能用旧专项版本覆盖更新的全市场版本。历史首次披露仍须独立核验，当前42家银行不是历史PIT股票池。


## 独立行业数据更新（2026-10-08）

数据管理移除策略因子和因子选择器；所有因子计算在因子计算页面操作。原有通用数据保留六项（证券/PIT、行情估值、财务、涨跌停、分红、基准），不自动更新因子。

行业数据独立列出银行基本面、财务与估值。行业更新请求 source_id=industry、groups=[bank_industry]，不可混入通用或免费更新组。检查计划和开始同步独立操作，共享任务锁和日期、磁盘参数。银行同步脚本 sync_bank_industry.py 是长期集成代码。

行情增量复查最近七天；财务复查最新报告期向前约四百天；分红完整复查所有阶段（不等于把所有分红记录加总）。原始返回和校验摘要、旧版本表保留；全部接口拉取成功后才切换银行专用视图。免费资产质量和资本补充若不是当天快照，会先刷新。银行子集不会推进全市场覆盖日期。

重合数据先核对银行、报告期、单位及合并报表口径。优先选择最新可得的 Token 非空字段；同一公告期优先更新标记，再使用最新采集版本；同次返回仍有冲突则留空并记录，不盲目取最大值。每股净资产采用 Token 优先、免费缺项补充。净贷款账面值与贷款本金等不同口径分开保留。直接股息率使用 daily_basic.dv_ttm，单位百分数；分红事实用于独立核验，不重复累加。历史研报原文及已有研究结果保留，不因新数据静默重写。历史首次披露/PIT校验限制继续保留。

验证：行业与通用更新隔离、因子请求拒绝、公告可得性/更新标记冲突、原始版本发布，以及采集失败不改变旧发布指针；配套前端构建和 API 计划检查。


## 逐指标来源与质量核验（2026-10-08）

统一银行表新增逐指标 `_source`、`_unit`、`field_lineage`；银行专用 `bank_metric_lineage` 长表按股票、报告期、指标唯一，保存来源/API/字段、原文件及校验码、PDF页码、口径、采集可得时间。源行的 source_id 只说明免费基础行，不表示所有混合指标都来自该源。

原始来源全部保留；价格单位元、比例单位百分数、财报金额元、每股值元/股。balancesheet.total_share 单位为股，daily_basic.total_share 为万股，不能一概乘一万。财报YTD不能视为单季度。每股净资产跨源差异超过0.01元标为口径待核；归母普通股账面值另以（归母权益－其他权益工具）/财报股数推导，未知其他权益工具保持空缺，后续股本事件必须另行调整。

`bank_dividend_events` 只采纳实施且已有除息日的唯一经济事件。版本重复归并，同事件已知字段补缺，未披露字段不凭空填零；仍冲突的事件排除并保存冲突记录。原始分红表包含预案、股东大会通过等过程版本，禁止直接累加。

已通过来源文件校验和采用值不变校验。源间口径差异及首次披露/PIT未认证状态明确保留，不能据此宣布历史回测输入就绪。`scripts/audit_bank_data.py` 可重复核验；发布前校验数据版本未改变，避免用旧审计覆盖新更新。界面只在核验对应当前Token版本时显示核验结果。
