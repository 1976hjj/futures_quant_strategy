# M3-A 因子目录与真实数据竖切

状态：已完成第一版内核、候选目录和真实数据竖切；尚未进行收益有效性判定。

## 1. M3-A 交付内容

- 安全表达式 AST：禁止未来引用、属性读取、下标、导入、任意函数和 `eval`；
- 不可变 Factor Registry：`factor_id + factor_version` 不能绑定到不同公式或规范；
- 来源治理目录：记录原始来源、公式编号、许可说明、适配说明和生命周期；
- 横截面预处理：MAD 去极值、标准化、行业固定效应与规模残差；
- 真实数据竖切：M2-A～M2-D checkpoint 血缘、RAW 因子值和覆盖率报告。

因子是否有效不属于 M3-A 的结论。IC、分层收益、换手、成本、稳定性和 OOS 证据进入 M4 Evidence Factory。

## 2. 第一批目录

内部机制候选共 12 个，覆盖：

- 动量与短期反转；
- 隔夜与日内价格行为；
- 成交量异常、波动率和 Amihud 风格流动性；
- 账面市值比、盈利收益率、规模；
- PIT ROE 与资产负债率。

另有 `wq-alpha101-reproduction`，它是对公开论文 Alpha#101 的原式复现，生命周期固定为 `RESEARCH_ONLY`。它不与 A 股适配版本共享名称或版本，也不代表已验证有效。

## 3. 外部因子如何进入系统

WorldQuant 101、GTJA191、券商研报、聚宽社区和 GitHub 实现均按同一流程处理：

1. 保存可追踪的原始论文或报告身份；
2. 核对算子定义、窗口、单位、复权口径和缺失值规则；
3. 先登记“原式复现”，只用于交叉验证；
4. 如需适配 A 股，创建新的 factor ID，写明涨跌停、停牌、ST、T+1 和行业体系差异；
5. 与现有因子做表达式哈希、收益相关和条件增量去重；
6. 进入预注册的 M4 检验族；失败、歧义和无增量结果同样永久保存。

没有稳定原始来源、授权边界不清或公式存在多个冲突版本时，只能进入来源待核区，不能注册为正式候选。

## 4. 真实数据竖切

第一轮使用招商银行、平安银行、五粮液在 2023-10-01 至 2024-03-31 的数据：

- 输入 354 个证券交易日行；
- 13 个因子；
- 输出 4,602 条 RAW 因子值；
- 所有非空输出均为有限数；
- 财务值要求披露日严格早于信号交易日，避免同日披露时点不明；
- 产物目录：`artifacts/m3a_vertical_slice`。

真实行业中性化暂缓到 M2-E 历史申万成员完成并发布。禁止用当前行业分类回填历史。

## 5. 当前边界

- 没有读取 Label 或 Holdout；
- 没有依据真实收益选择因子方向或窗口；
- 没有把任何候选标记为 VALIDATED、CORE 或 DEPLOYABLE；
- 不全量物化 18,180,017 行行情乘以全部因子。正式系统按实验所需日期、Universe 和版本生成不可变缓存，避免制造数亿行无用副本。
