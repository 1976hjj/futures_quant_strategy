# ADR-0004：先完成可信竖切片，再扩大因子产能

- 状态：Accepted
- 日期：2026-09-01

## 背景

批量导入 Alpha158、GTJA191 或 WorldQuant101 会迅速制造大量结果，但在时间、数据、标签和统计语义未经验证时，这些结果没有可信价值。

## 决策

Alpha158 前先完成一条端到端竖切片：一个已发布数据版本、一个历史 Universe、一个 Label、五至十个哨兵因子、Evaluator、成本测试、Walk-Forward、审计和状态事件。

## 后果

- M1 从契约和敌对合成数据开始；
- M3 只实现少量可手算因子；
- M4 通过外部交叉验证后才开始 Alpha158；
- “文件数量”或“因子数量”不作为早期进度指标。
