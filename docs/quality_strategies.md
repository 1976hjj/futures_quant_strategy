# 优质策略页

入口：前端顶部“优质策略”；API复用策略服务8773。

分类为小市值、银行、因子加权。这里记录所有者保留的研究候选，不改变
研究宪法、因子认证状态或Deployable状态。初始规则和证据哈希位于
`config/quality_strategies.json`，实际模型计算和新增记录位于
`data/quality_strategies/`，不用提交原始研究文件。

## 历史记录

归档回测曲线、指标、年份收益和规则版本一起保存。银行主记录采用修正后的
2020—2025周期股息口径（记录版本2），旧365天结果作为独立历史对照。
小市值附带2016—2019弱区间。
“记录已有策略”从完成的历史回测复制独立证据，不能由客户端指定收益数值。
记录动作不是研究晋级或实盘认证。

## 接口

曲线支持悬停、轻触及键盘左右键查看对应交易日的收盘回测账户：累计及当日收益、
截至当日的回撤、初始资金、权益、现金、股票市值、实际仓位和持仓数量。
累计收益使用回测初始资金，不能以图示归一化起点或用户当前填写的参考资金代替。
已有结果从其哈希匹配的独立回测文件读取日账，不读取今天的行情来重估旧持仓。
未记录的字段明确显示缺失。后续重算保存逐日实际股数和回测估值，悬浮框展示
当天全部实际持仓。所有类别共用固定行位：按历史日期依次分配，持续持有的股票
不因市值、仓位或输入顺序变化挪行；换入股票填补换出股票的空位，暂未补入时
显示空位。光标前后跳转使用同一套行位，不把选股目标或最新持仓冒充历史持仓。
日期栏区分本轮建仓日与最近买卖日，均从该结果自身的实际成交记录还原：加减仓
只更新最近买卖日，清仓后再买才重置本轮建仓日，分红送转不计作买卖。
缺少可核对的成交证据时显示未记录；只修正展示，不改写原回测或重跑策略。

- `GET /api/v1/quality-strategies`：按category读取候选。
- `GET /api/v1/quality-strategies/{id}`：规则、证据和最新结果。
- `POST /api/v1/quality-strategies`：从历史job_id记录候选。
- `POST /api/v1/quality-strategies/{id}/calculate`：生成持久化计算任务。
- `GET /api/v1/quality-strategies/jobs/{id}`：阶段、进度、错误。

计算由独立进程执行，不在API进程修改全局回测函数；记录失败任务。
数据更新与信号读取互斥。规则更改和数据更正应生成新记录，不能覆盖旧证据。
