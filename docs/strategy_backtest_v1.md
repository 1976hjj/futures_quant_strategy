# 通用策略回测 v1

## 定位

这是独立于 M4 因子检验的连续账户回测模块。它只读取已经发布的因子版本，不修改因子资产，也不把某一组 A/B/C/D 对照方案写死在代码中。

前端通过“策略回测”菜单进入；后端是独立进程，默认监听 `127.0.0.1:8773`。

## 一条配置如何变成回测

1. 选择历史全 A 的时点股票池，并排除当日 ST、上市时间不足的股票。
2. 按配置逐条应用高端或低端分位过滤。
3. 将每个打分因子转换为当日横截面百分位，按方向和权重合成总分。
4. 选综合排名前 N 只；原持仓仍在“保留排名”以内时优先保留。
5. 信号使用当日收盘后已知的数据形成，下一交易日开盘尝试交易，避免同日收盘信号同日成交。
6. 连续维护现金、持仓和净值，并计入佣金、印花税、滑点、冲击、涨跌停、停牌和成交额参与率约束。

## 当前可配置项

- 日期区间、股票池基础过滤；
- 任意数量的打分因子、方向和权重；
- 任意数量的高端/低端分位过滤规则；
- 目标持股数、保留排名、调仓交易日间隔；
- 初始资金、现金保留比例；
- 买卖佣金、印花税、基础滑点、冲击和最大成交额参与率。

## 输出

- 预检：共同数据区间、交易日数和预计调仓次数；
- 单日预览：各层股票数量、过滤结果及最终入选名单；
- 回测报告：日净值、累计/年化收益、最大回撤、波动率、夏普、成本、换手、成交与拒单统计、逐年收益和期末持仓。

## v1 的明确边界

- 当前只支持 `ALL-A-PIT`，还未加入沪深 300、中证 500 等可选基准股票池；
- 当前组合是等目标金额持仓，还未加入行业/风格中性优化器；
- 当前使用因子的 `RAW` 版本，打分时统一做横截面百分位转换；
- 日线成交模型是研究级近似，不等于逐笔实盘撮合；
- 相同配置会生成独立运行报告，便于审计，不会覆盖历史报告。

## 启动

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_strategy_backtest_api.ps1
```

前端仍使用原来的启动方式，默认从 `http://127.0.0.1:8773/api/v1` 调用本模块；也可以用 `VITE_STRATEGY_API_URL` 覆盖地址。

## 串行任务队列

单因子回测、通用因子策略回测和多组合轮动回测共享同一条 FIFO 队列。系统始终只运行一个
回测子进程；新任务在已有任务运行时返回 `QUEUED`，当前任务完成、失败或取消后自动启动队首任务。

- `QUEUED`：页面显示队列位置和前方任务数，不显示伪进度；
- `RUNNING`：继续使用任务自己的进度文件、阶段、心跳和交易日进度；
- `PASS`、`FAIL`、`STOPPED`：分别表示完成、失败和取消；
- 等待任务可以直接取消，运行任务停止后才会释放槽位；
- 队列状态写入独立的 `state.json`，API 重启后恢复等待任务；
- 单因子完成结果仍进入单因子报告，通用策略与轮动结果仍进入历史回测结果。

队列摘要可通过 `GET /api/v1/strategy/queue` 查询。
