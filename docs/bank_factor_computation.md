# 银行因子统一计算

数据管理只保留通用、行业来源的采集和覆盖。标准事实、派生输入准备随因子计算自动执行。

## 页面操作

1. 在数据管理更新所需来源。
2. 在因子计算选择银行因子或银行板块择时，像JQDATA一样选择单项或批量项目。
3. 设置日期，预检或启动计算。后台核验标准事实，准备所需派生输入，并分派各自脚本。
4. 在同一任务进度、日志和结果中查看错误及缺口。板块结果可展开“查看因子数值与覆盖情况”，按日期分页。

个股银行因子由 `publish_bank_factor.py` 计算；板块由 `publish_bank_sector_factor.py` 计算。
二者复用银行标准事实及基础公式，板块额外准备收益篮子、宽基和历史覆盖。
银行个股目录为16项，新增“银行·日PB”基础因子。板块不要求先发布全部个股因子，直接复用同一份基础输入。
混合批次的M4及联合去重只包含个股因子。
本轮板块计算研究值和数据覆盖，不生成仓位、收益标签或仓位回测。

## 依赖和版本

### 分红周期股息率（2026-10-12修正）

个股“分红周期股息率”和“质量门槛后周期股息率”升级为2.0.0，分别使用
`cash_yield_cycle`、`gated_cash_yield_cycle`。历史ID中的`365`仅为兼容，旧1.0.0仍是365日口径。
旧输入的`cash_yield365`保留作对照，新版因子和板块计算不再使用它。

- 年度一次分红取最近完整年度金额，不乘2，不叠加两个年度。
- 同一年度中期、末期分红组合成年度金额。已有稳定分期记录时，新中期替换去年同期，
  保留此前末期，按所属期间覆盖一年，不按现金发放日期是否超过365天删除。
- 首次增加中期分红时，不把之前整个年度再加半年；先保留最后完整年度参考，并标记频率过渡。
- 缺少预期分期、没有历史实施记录、期间异常、同期间多笔尚未核对、长期过期参考均留空并附原因；
  缺事件不能证明不分红。明确的零金额实施记录可为0，拟派息不提前计入。
- 送转股折算成当前每股单位；配股等非送转变化仍需要独立来源认证。
- 低于2.5%或高于6%的图形明细标记需要核查，数值不裁剪、不为满足区间而调整。

板块股息率历史分位升级2.0.0，依赖PB的低估高息占比、质量合格低估高息占比、估值分化升级3.0.0。
四者依赖新的周期股息率；旧365日派生包不能用于新版本。
板块因子先计算各股自身历史分位再汇总；描述图的百分比曲线是各股股息率均值，两者含义不同。
`recompute_bank_dividend_cycle.py`重算两个个股因子以及同一依赖版本的10个板块指标。
图与反弹研究分别由已有绘图和研究脚本生成新版本，旧归档、发布与报告保留用于追溯。

默认使用当前本地归档，数据准备不下载来源、不调用Token接口。
脚本及API保留 `source_mode=frozen` / `bank_source_mode=frozen` 用于复现冻结来源。
来源错误、完整性失败和计算异常会报错；覆盖不足保留空值和原因，不作0。
任务完成不表示每个日期都有有效值，历史披露/行业认证限制仍保留。

银行开放研究范围仍为2020-01-02至2025-12-31，计算自动带入所需预热历史。
标准事实、派生输入和因子结果各自保存不可变版本及上游ID；旧归档和因子发布不改写。
相同来源、日期、配置和代码可复用；来源修订或范围变化时生成新版本。
目前不是所有指标都实现按受影响日期逐分区的细粒度增量。

日PB独立读取已有 `research.daily_basic` 归档，保留每行来源快照和原始载荷ID，逐行核验发布值。
它不依赖普通股净资产PDF处理，也不宣称重新从财报独立计算全部PB。
PB预热从2016年开始，仅使用银行上市且属于银行行业期间的记录；缺失日期不填充，未上市期间不补造。
当前归档的股息率及年度盈利收益率同样尝试从2016年预热，用原公式按当时已披露的事实计算；
历史财报缺失仍保留空值。冻结复现来源仅使用其实际拥有的历史，不替换冻结财务证据。
收益篮子及宽基仍使用2019年起的独立预热历史。输出研究区间保持2020年至2025年。
PB分位、低估高息占比、优质低估高息占比、估值分化四项板块指标升级为2.0.0，使用日PB；旧版结果保留。
原“普通股账面市值比”仍保留普通股净资产、披露日和股本调整口径，与日PB分开。
历史不足或覆盖不足时，结果展示有效家数、需要家数及具体缺失输入。旧派生包缺日PB时拒绝用于新版PB板块指标。

## 财务和宽基缺口补充

`supplement_bank_financial_facts.py`只补已归档财务事实中缺少的银行、报告期和指标键。
使用已有公告索引、原始年报文件哈希和当年表格列；API数值仅用于交叉核对，不能单独证明历史可用性。
支持跨页表头、拆行及脚注，扫描页可通过`--ocr-pages CODE:YEAR:FIRST-LAST`转录，并核对原始表格。
`--code`限定仍有缺口的银行；API候选与原表不符或扫描表头错层时，
可用`--reviewed-cells`提供与原始PDF哈希、年份、指标及页码绑定的原图核对记录。
复核记录只能确认原表当年列，不可直接注入数值：数值仍须匹配该页原始单元格，并保留复核理由。
补充事实独立保存到`data/features/bank_original_evidence`，接入`config/bank_factors.json`后，
普通因子计算自动使用新来源；不需要新增页面操作。已存在的事实不会被覆盖，冻结复现仍读取原冻结包。
新增利润同比使用同一份当年报告中的可比上年列，按当年报告公告日期可用，不提前回填上年原始值。

`sync_bank_timing_benchmark.py --fill-gaps`仅向已有沪深300全收益序列补缺失日期。
从中证指数官网取得缺日及相邻日期，核对重叠点位在官网显示精度内一致，保留全部已有点位。
宽基新版本会使派生缓存失效并重新计算连续历史；价格指数不能替代全收益指数。
IPO之前不存在的行情、不足504日的上市历史，以及尚未通过原始列或口径核验的财务事实，仍保留缺失原因。

## 接口

- 8771的 `/api/v1/factors/jobs`、`/factors/batches` 同时接受银行个股和板块因子，按类型分派。
- `/api/v1/factors/batches/preflight` 检查依赖范围并展示已知输入覆盖问题。
- `/api/v1/factors/sector-values` 按指定发布版本、因子和分页参数读取板块数值，页大小上限100。
- 8774的 `/api/v1/data/processing` 内部分层接口保留用于复现和排查，日常页面不展示独立操作区。
- 依赖准备任务在 `reports/bank_factor_dependencies` 留存状态，并与来源更新互斥。

## 存储和内部排查

标准事实与板块结果保存在 `data/bank_processing_store`，派生包保存在 `data/bank_timing_store/packs`。
文件哈希校验失败时拒绝复用。来源更新与依赖准备互斥，任务进程退出会报告失败。
内部分层接口支持 `inventory`、`plan`、`jobs`、`gaps` 和 `values`；分页大小上限100。

早期[指标接入记录](history/bank_sector_timing_integration.md)、[基础包设计](history/bank_timing_data_design.md)
和[分层处理接口记录](history/bank_data_processing_workbench.md)集中保留在 `docs/history`，供复现和排查。
日期固定的银行研究脚本集中在 `scripts/research`，不参与日常因子计算。

## 银行板块信号研究

`scripts/research/research_bank_sector_timing.py`复用已经发布的10项板块指标。
所有输入必须绑定同一派生包；换手率观察独立保留原始来源，按历史银行范围和交易日窗口计算。
它研究低估、趋势改善和交易升温之后的20/60/120日含分红收益、相对宽基收益及区间风险，
属于已暴露历史上的信号诊断，不是仓位回测，也不进入个股横截面M4流程。

- `prepare`先冻结实验、90项检验家族及阈值，再生成只含当时及此前信息的特征。
- `analyse --run-dir <prepare输出目录>`独立生成T+1收盘参考起点的后续标签、统计结果和报告。
- `render --run-dir <研究目录>`只复用同一证据生成新的报告版本，不重新选择参数或覆盖旧报告。

结果集中保存在`reports/bank_sector_research/<运行时间>/`。
跨银行篮子或宽基断点的收益窗口留空；推断保留交易日间隔并处理重叠观察，所有计划检验一起校正。
阈值、方向、日期、来源哈希、全量成功/不支持结果、分年和冻结分组结果均保留，以便后续独立复核。

`scripts/research/plot_bank_sector_pb.py`用于归档日PB的全历史均值图与数据诊断。
它按历史行业区间等权聚合有效正PB，独立重算全部日期并逐项抽查；只读取开放截止日以前的数据。
原始PB疑点保留并标注，不自动剪裁、修复或覆盖既有因子。输出集中在同一研究目录下的独立版本中。

`scripts/research/research_bank_dividend_horizons.py`继续研究分红周期股息率的期限与条件。
`prepare`冻结60/120/126/252交易日、趋势/活跃度/分红稳定及高位内部对照；
`analyse <研究目录>`仅使用截至2025年末的标签，保留同一批可观察一年日期和固定入区事件。
本轮128项检验连同此前252项联合校正；绝对股息率分桶仅作描述，不事后选择最佳门槛。
`verify_bank_dividend_horizons.py <研究目录>`独立检查收益路径、历史排名、HAC、检验家族与年份混杂；
加`--notes-only`从已冻结结果生成探索发现说明。2026图形授权不扩展为收益检验授权。
