# 通用多组合轮动回测设计

状态：设计已确认，等待分阶段实施。

## 目标

在现有“通用因子选股”之外增加“多组合轮动”模式。轮动策略引用两个至八个候选组合，
根据可配置的历史信号动态分配资金。因子选股和轮动共用成交、持仓、费用、净值、历史任务
与详情页面，禁止复制一套口径不同的账户引擎。

首个模板为“价值 / 小盘轮动”，但请求模型和界面不得写死风格名称，以便扩展价值/成长、
大盘/小盘、红利/科技、行业、ETF及股票/现金轮动。

## 页面结构

策略研究提供两个入口：

1. 通用因子选股；
2. 多组合轮动。

轮动配置页延续现有视觉体系：左侧依次为基础设置、候选组合、轮动信号、资金分配、风险与
成本；右侧为固定的预检、历史日期预览和运行控制面板。

## 候选组合

- 支持二至八个候选组合，类型预留因子选股、指数、ETF、固定股票池和已保存策略；
- 因子选股组合包含股票池、打分因子、过滤因子、方向、权重、目标数量、保留排名、成分
  更新周期、个股上限、行业上限、行业中性和缺失值规则；
- 候选组合必须引用不可变的因子 release 和策略版本，历史结果不得被后续编辑改变；
- 重合持仓只交易目标差额，禁止先清仓再回购共同持仓。

## 轮动信号与资金分配

- 比较指标支持区间收益、超额收益、风险调整收益、回撤和多指标综合分；
- 参数包括回看周期、判断频率、切换阈值、连续确认天数、最短持有期和阈值内行为；
- 信号固定在当日收盘后生成，最早于下一交易日开盘执行；
- 分配模式支持胜者全仓、胜者倾斜、Top-N和按得分分配，并预留现金防守状态；
- 首版同时验证20日收益差超过1%的胜者全仓，以及70/30胜者倾斜。

## 持仓、执行与成本

复用现有连续账户模型，并继续执行A股整手、科创板、T+1、停牌、涨跌停、流动性、退市和
现金约束。每次调仓保存调仓前后组合、触发信号、目标与实际持仓、保留/买入/卖出、重合
持仓净调整、未成交订单和仓位变化。

成本分项包括买卖佣金、最低五元、印花税、过户费、滑点、市场冲击、成交参与率及风格切换
成本。账户类型需支持个人股息红利差别化税、机构口径和显式忽略三种模式。

## 预览与结果

运行前按任意历史日期预览各候选组合成分、因子分、区间收益、轮动排名、阈值判断、预计
交易、费用、行业分布与重合度。

运行后进入统一回测历史列表并增加策略类型标签。公共详情继续展示收益、回撤、年度交易、
逐笔费用和仓位；轮动详情额外展示轮动净值、候选组合影子净值、基准、状态背景带、切换
标记、切换记录、各组合占用时间与收益贡献、静态配置对照和切换成本。

## 价值 / 小盘首版数据约束

- 价值组合使用盈利收益率、现金流市值比、账面市值比和PIT质量因子，并进行行业中性或
  行业限额，避免银行、煤炭集中；
- 小盘定义使用可交易流通市值而非总市值，并通过盈利、现金流、波动和流动性过滤避免
  壳股与不可成交暴露；
- 影子信号组合可各含一百只股票，百万元实盘模拟组合建议持有二十至三十只，以控制最低
  佣金、滑点和操作成本；
- 正式验证前必须补齐历史行业归属，并把目标因子发布到统一的长区间。

## 行业数据准备状态

2026-09-09 复核发现，原 M2-E 归档只拉取了 `is_new=N` 的历史退出记录，没有
`is_new=Y` 的当前行业成员，因此无法正确建立当前截面行业归属。现已补抓并入库：

- 当前成员 5,971 条，覆盖 5,906 个证券代码；
- 历史退出记录 2,011 条，覆盖 1,646 个证券代码；
- 原始表共 7,982 条，研究视图对完全重复键去重后为 7,981 条；
- 2026-08-31 研究股票池 5,306 只全部可匹配行业，缺失 0 只。

年末可投资股票池的 PIT 行业覆盖抽查如下：

| --- | ---: | ---: | ---: | ---: |
| 2020-12-31 | 3,956 | 3,905 | 51 | 98.71% |
| 2021-12-31 | 4,493 | 4,478 | 15 | 99.67% |
| 2022-12-30 | 4,927 | 4,921 | 6 | 99.88% |
| 2023-12-29 | 5,214 | 5,209 | 5 | 99.90% |
| 2024-12-31 | 5,245 | 5,242 | 3 | 99.94% |
| 2025-12-31 | 5,282 | 5,282 | 0 | 100.00% |
| 2026-08-31 | 5,306 | 5,306 | 0 | 100.00% |

2020–2024 的少量缺口来自上游成员变更记录之间的日期空档，不能为了追求 100% 覆盖而
使用未来行业回填。首版对这些股票标记为 `UNKNOWN`，行业中性时不将其归入任何已知行业，
并在预检和回测报告中显示当日缺失数量与比例。

原始历史表不删除旧归属。回测时必须先限定
`in_date <= 信号日 < out_date`（`out_date` 为空时视为未退出），再对同一股票选取
`in_date` 最新的唯一记录。这一点是回测引擎的强制 PIT 规则，不允许直接把原始成员表按
`ts_code` 连接到日截面。
