# 实验协议草案 v0.1

状态：待补齐既定五维规范和数据审计后冻结。本文新增规则为建议，不代表既定 Risk Score 已被修改。

## 1. 研究对象与样本

分别测试沪深300、中证1000、中证2000。指数标识、价格/全收益类型、基日、发布日期和数据版本以数据源元数据核对，避免混用中证2000与国证2000。

主表采用三个指数、全部策略和五维输入共同有效的日期区间，剔除共同预热期。补表使用各指数自身最长有效区间，并拆分发布前回溯/发布后区间。每张表明确起止日期、交易日数、预热长度、数据版本和样本角色，不直接跨不同区间排名。

训练、验证、测试按时间顺序划分；具体日期在数据权限和覆盖审计后登记。训练用于必要的估计，验证用于预先列明的选择，测试用于一次性评价。若历史已经参与五维设计，则相应时段只能算开发样本，不能重新宣称样本外。未经释放的 holdout 不读；本批方案没有访问它。

“三指数统一”默认指公式、权重、窗口、阈值和算法完全一致。若原评分是全市场单一分数，则三指数使用同一目标仓位路径；若原评分规定指数内输入，则分别计算但不得分别调参。此项以既定五维定义为准。

## 2. 六个核心策略

| ID | 策略 | 建议固定规则 |
| --- | --- | --- |
| B0 | Buy & Hold | 起始建立100%指数敞口，持续持有 |
| B1 | Constant Exposure | 固定目标仓位为同一评价样本 B5 的平均实际敞口；事后诊断基线 |
| B2 | MA200 | 收盘价大于或等于200日简单均线时100%，否则20% |
| B3 | MA20/MA60 | 20日简单均线大于或等于60日简单均线时100%，否则20% |
| B4 | Volatility Targeting | `clip(15% / sigma20, 20%, 100%)`，sigma20为最近20个日简单收益的样本标准差乘sqrt(252) |
| B5 | Risk Score | 严格使用既定五维公式，按下表映射 |

15%与20日是未优化的基线建议，不是学术标准或已验证最优值。波动率为零时 B4 目标为100%；数据缺失、非数值或负值按数据异常处理。B2/B3/B4 同样不加杠杆、不做空，最低目标20%，保证约束一致。

| Risk 区间 | 目标仓位 |
| --- | --- |
| [0,20) | 100% |
| [20,40) | 85% |
| [40,60) | 65% |
| [60,80) | 40% |
| [80,100] | 20% |

Risk 超范围不是静默截断理由，应检查评分规范和数据。五维缺失不当作低风险；预热不足不计入主比较，中途缺失应保留记录并暂停形成新有效结论，不能事后删除坏行情日期。第一版不额外引入平滑、滞回或最短持有期；Risk Flip 先诊断，后续改进另记实验版本。

B1 的固定值采用持有区间时长加权的 B5 实际敞口平均数，不用全期收益反推最优仓位。固定目标每日再平衡后实际敞口仍会漂移，因此另报实际均值与 B5 均值之差。B1 使用测试期统计只服务事后比较，不参与 B5 信号或参数。附加 B1-PIT 使用训练期 B5 平均敞口，并在后续测试期冻结，作为可事前设定的补充对照。

## 3. 时序、账户和成本

建议每日收盘形成信号，下一交易日开盘调整到最新目标。均线、波动率及风险分数只能读取信号截止时已可用的数据。目标不变也每日向目标再平衡，因此调档次数不等于实际交易次数。

账户连续维护单位份额和现金：先用旧持仓核算前收盘到次日开盘的涨跌，再在开盘按交易前净值计算调整量并扣费，最后核算开盘到收盘的涨跌。不可把新仓位乘以包含旧仓位隔夜风险的整个收盘到收盘收益。成本导致的目标偏差保留在实际敞口中；实际敞口因漂移短暂低于20%不等于主动选择低于底仓目标。

若只有收盘数据，则另立明确标注的“下一交易日收盘调仓”实验：T日信号在T+1收盘执行，新仓位从该成交点以后承担风险；不能伪装成开盘执行。缺少可用开盘数据时不拼接虚构开盘价。

第一阶段是指数敞口的研究账户，不能直接称为可交易业绩。优先比较同口径全收益，价格指数结果单独标识；若使用全收益因子计入分红，不能再重复计入现金分红。用于信号的价格序列也要固定并记录。

建议现金利息和无风险收益在主实验均设为0，附表可使用当时可知的现金利率序列。所有策略采用同一口径。假设单边综合交易摩擦为成交名义金额的5bp，另列0/10/20bp敏感性；这是压力假设，不是 ETF、股票或期货实际费率。起始建仓计费，终点只估值、不强制平仓，六策略一致。

真实 ETF 或期货落地会涉及跟踪误差、历史可交易区间或合约机制，留待后续单独研究，不能用假设摩擦宣称已验证实盘可行性。

## 4. 指标定义

设净值 V 初始为1，日净收益为 r，日无风险收益为 rf，实际历年长度为 Y，年化交易日数固定252。

| 指标 | 口径 |
| --- | --- |
| CAGR | `(V末/V初)^(1/Y)-1`，Y按实际日历天数/365.25 |
| MaxDD | `max(1-Vt/截至t历史最高净值)`，报正的损失幅度 |
| Calmar | CAGR / MaxDD；MaxDD为0时记NA |
| Sharpe | `sqrt(252)*mean(r-rf)/std(r-rf, ddof=1)`；零标准差记NA |
| Annualized Volatility | `sqrt(252)*std(r, ddof=1)` |
| Downside Capture | 在同指数 B0 月收益<0的完整月份，策略平均月收益/B0平均月收益×100%；无下跌月记NA，越低通常越好 |
| Worst Year Return | 完整自然年收益最小值；首尾残年另列，不混入；无完整年记NA |
| Recovery Time | 最大回撤对应峰值到首次恢复该峰值的交易日数；另报谷底到恢复、全样本最长水下时长 |
| Average Exposure | 持有区间时长加权实际敞口均值；另报目标均值和实际最小/最大值 |
| Exposure Changes | 目标档位发生变化次数及年化次数，初始建仓不算调档 |
| Turnover | 每次交易绝对名义金额/交易前净值的累加及年化值；不除以2，含初始建仓 |

未恢复回撤标为“截至样本末仍未恢复，已持续N交易日”，是右删失结果，不能记0或当作完整恢复时间。Downside Capture 必须同时给出下跌月份数，负数可能表示下跌月份策略平均收益为正。可另报日频下行捕获，但不能和月频混用。

另列上涨月捕获、CAGR差、回撤减少百分点、回撤相对减少比例及成本拖累。例如回撤40%降至30%，减少10个百分点，相对减少25%。平均仓位低并非优越指标，只用来解释风险差异。

## 5. 压力与反弹诊断

先登记事件窗口及其来源，再看策略曲线；下列机械定义可作为补充草案，不能用于本版交易信号：

| 类别 | 建议机械识别规则 |
| --- | --- |
| 单边熊市 | B0从历史高点回撤达到20%的水下事件，回看其峰值作为起点 |
| 快速暴跌 | 任意5交易日累计收益≤-10%的窗口，重叠窗口合并 |
| 高波动 | 20日年化波动率超过训练期该统计量90%分位数的连续区间 |
| 震荡市 | 固定不重叠60交易日块，区间收益绝对值≤5%，高低价区间幅度≥10% |
| 急跌后快速反弹 | 快速暴跌事件结束后20交易日内，从期间最低收盘上涨≥10%；末端不足20日单独标识 |

各类别可以重叠，同一冲击不能当作独立多次成功。峰谷及反弹标签用到了事后路径，仅作诊断；既要展示合格事件，也要展示未提前降仓、未及时加仓的失败事件。

每个窗口报告：事件前20日和5日敞口、首次减仓日期、首次进入40%及以下目标的日期、相对事件起点的延迟、窗口局部MaxDD、连续账户实际回撤、谷底仓位、谷底后5/10/20日收益与上涨捕获、恢复至85%及以上目标的交易日数。没有对应动作记“未发生”。窗口开始不重建仓位，继承全样本账户。

Risk Flip 建议定义为一次调档后5交易日内发生反向调档，按后一次反向事件计数；同时报告20/40/60/80附近分数分布、目标档位停留时间、实际交易次数、换手与费用，避免把正常仓位漂移交易误判为评分翻转。

## 6. 判定与稳健性

以下是待冻结的业务评价建议，数值不是文献结论：

- 相对 B0 的“明显降低回撤”：MaxDD相对减少至少20%，且绝对减少至少3个百分点；同时显示CAGR代价，不由此直接宣布择时有效。
- 相对 B1 的择时证据：净Calmar提升、MaxDD下降且下行捕获改善；若收益、恢复或其他主指标明显恶化，结论为有取舍，不能写全面优于。
- 相对简单风控：逐项比较B2/B3/B4；未胜过其中某个策略须明确列出。跨风格候选价值要求至少两个指数的样本外比较支持，并完整展示第三个指数，不能用三指数平均值掩盖失败。

这些仅是经济意义筛选条件，不能代替统计不确定性。固定同一日期块同步重采样三个指数及其所有策略，保留市场间相关性；建议20交易日移动块、2000次重复，给出配对Calmar差和MaxDD差的95%区间。B1的事后平均敞口匹配应在每次重复中按同一协议重建。路径指标重采样属于近似诊断，不是独立危机样本的替代。

若对B5与B1/B2/B3/B4的三个指数差异进行显著性声明，预先登记12组比较及涉及指标，按完整检验家族校正；不可只挑显著的一项。样本太短、事件太少或区间跨0时，应写“证据不足”。经济意义门槛、统计证据和成本稳健性分别报告。

正式结果只允许分为：存在增量证据、仅体现低敞口收益、表现有取舍、未发现优势、证据不足。验证不能预设必须成功，也不能因首轮失败而在同一测试集上不断优化后宣称样本外通过。
